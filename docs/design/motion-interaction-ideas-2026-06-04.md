# 主站 GSAP / Motion 交互想法 - 2026-06-04

## 当前判断

`/music` 页已经做过一轮 GSAP 改造，并且后续又做过性能收敛，所以不建议马上重复堆新动效。后续如果继续加强 music，应优先做小范围 polish，而不是继续加重滚动监听、filter、blur 或大量 DOM 动画。

当前更适合先补两类全站基础能力：

- 页面转场：让站内页面切换不再是硬切。
- 磁吸按钮：让主按钮延续现有方向灌注效果，同时增加更细腻的鼠标响应。

## 候选效果

### 1. Page Transition 页面转场

适合位置：

- 首页到 music / anime / game / gallery / updates。
- 子页面返回首页。
- 日志页、游戏页、CV 页这类跳转感较强的入口。

建议形式：

- 使用浅色幕布覆盖页面。
- 幕布进入时轻微放大或从按钮点击方向扩散。
- 新页面准备好后，幕布淡出并露出首屏。
- 尊重 `prefers-reduced-motion`，降级为短淡入淡出。

风险：

- Remix 路由切换很快时，转场如果强行拖长会显得卡。
- 不适合让所有普通锚点滚动都触发完整转场。

本轮落地：

- 先做全局轻量幕布转场。
- 保留显式事件 API，后续可让重点按钮触发更完整的转场。

### 2. Magnetic Button 磁吸按钮

适合位置：

- `探索完整榜单`
- `追随指引之风`
- `返回首页`
- `登录留言`
- gallery / music 的 CTA

建议形式：

- 鼠标进入时保持原有方向灌注效果。
- 鼠标移动时按钮本体轻微跟随，内容层有更小幅度跟随。
- 鼠标离开时用 `expo.out` 弹回。
- 只移动 `transform`，不改 `top/left/width`。
- reduced motion 下关闭磁吸，只保留静态可点击状态。

风险：

- 幅度太大容易像按钮漂走。
- 移动端无意义，应只在 mouse / pen 指针启用。

本轮落地：

- 直接增强现有 `GsapFillLink` / `GsapFillButton`。
- 所有已接入这两个组件的主按钮自动获得磁吸行为。

### 3. ScrollTrigger Pinning 固定场景叙事

适合位置：

- `赛博终端`
- CV 经历
- 更新日志大版本档案

建议形式：

- 滚动到 section 后固定短时间。
- 左栏、主内容、右栏按滚动进度依次点亮。
- 只做一个核心模块，不全站滥用。

优先级：

- P2。适合后续单独做一轮。

### 4. Horizontal Scroll 横向滚动画廊

适合位置：

- anime 卡片
- game 平台
- gallery 图片
- 更新日志版本目录

建议形式：

- 竖向滚动驱动横向位移。
- 当前卡片清晰，非当前卡片降低透明度。

优先级：

- P2。适合视觉内容多的页面，不适合正文区域。

### 5. Image Mask Reveal 图片显影

适合位置：

- gallery
- xiao
- music 艺术家图片
- game 封面

建议形式：

- clip-path 从左到右或中心向外打开。
- 图片从低饱和/轻模糊恢复正常。
- 动效像纸面揭开或胶片显影，不做过重科技扫描。

优先级：

- P1。很适合图片页。

### 6. SVG Path Draw 路径绘制

适合位置：

- CV 时间线
- 更新日志时间线
- section 分隔线

建议形式：

- 滚动时细线逐步绘制。
- 节点进入视口时点亮。

优先级：

- P2。

### 7. Spotlight / Cursor Follow 局部光标响应

适合位置：

- 赛博终端
- 留言板
- 卡片组

建议形式：

- 鼠标附近出现非常柔和的局部光。
- 只在当前模块内部响应，不做全站自定义鼠标。

优先级：

- P2。

## 不建议优先做

- 全站自定义鼠标。
- 每个 section 都 pin。
- 大量 blur/filter scrub。
- 中文正文逐字动画。
- 所有卡片统一 3D tilt。

这些效果容易降低阅读体验，或者带来性能问题。
