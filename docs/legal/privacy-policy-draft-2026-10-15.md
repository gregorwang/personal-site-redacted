## 1. 不登录时我会收集什么

- **主题 cookie（`theme`）**：记住你选的浅色 / 深色，用于首屏渲染。
- **访客 cookie（`cyber_terminal_visitor_id`）**：只有你在首页终端里触发"领取"类互动时才会设置，有效期 1 年，用于防止重复领取。
- **浏览器本地存储**：
  - `localStorage`：Nemesis 聊天记录（最多 20 个会话）和"已阅读隐私提示"标记，只在你的设备上，不会自动上传。
  - `sessionStorage`：音乐页的临时缓存、首页终端的一次性提示，关闭标签页即清除。
- **服务器日志**：网站运行在 Cloudflare Workers 上。Cloudflare 会处理你的 IP 地址、User-Agent、访问路径等，用于提供服务和安全防护。我在 Worker 里开启了调用日志，所以这些请求信息会出现在我的 Cloudflare 日志里。
- **限流用的 IP**：留言、登录邮件等接口会按 IP 计数限流，计数记录里包含你的 IP，过期后失效。

本站目前**没有**接入 Google Analytics 等第三方统计、广告或追踪脚本。[待确认：上线前再 grep 一遍，如果以后加了统计，要回来改这里。]

## 2. 登录时我会收集什么

你可以用 Google、Microsoft 或邮箱魔法链接登录。

- **账号信息**：邮箱、昵称、头像（来自 Google / Microsoft 授权，或你自己填写的邮箱）。
- **登录会话**：会话令牌、过期时间、登录时的 IP 和 User-Agent。会话有效期 7 天。
- **第三方授权令牌**：使用 Google / Microsoft 登录时，认证库会把对方返回的授权令牌存进我的数据库的 `account` 表。[待确认：是否需要保存；如果不需要，应当改配置不存。]
- **魔法链接邮件**：链接 5 分钟内有效。邮件通过 Resend 发送，Resend 会处理你的邮箱地址和发信内容。
- **管理员权限**：站长账号有管理员角色，普通用户没有。

## 3. 留言板

- 你提交的留言内容、显示名称、提交时间、关联的账号 ID，会存入数据库。
- 新留言默认是"待审核"，审核通过后才会公开显示。
- 新留言提醒会通过 HTTPS 发给我自己的私有通知服务并转发到我的微信，里面包含留言内容和显示名称，只给我自己看。
- 请不要在留言里写你不想公开的信息。已公开的留言可能被他人截图或转载，我无法控制。

## 4. Nemesis AI 聊天

这是本站隐私上最敏感的一块，请认真看。

- **日常聊天不入库**：普通对话只保存在你自己浏览器的本地存储里。清理浏览器数据、换设备、用无痕模式，记录都会消失。
- **会发给第三方模型**：为了生成回复，你的消息和少量上下文会发送给第三方大模型服务，目前包括 **Google（Gemini）** 和 **DeepSeek**。另有 xAI（Grok）的接入代码，当前处于关闭状态。[待确认：以 `wrangler.toml` 里的 `NEMESIS_GROK_ENABLED` 为准，上线前再看一次。] 这些服务商按各自的条款和隐私政策处理数据，我无法控制。
- **安全审核会留存**：以下情况，这一轮的问题、AI 回复和最近最多 10 条上下文（每条截取前 1000 字）会写入后台审计表，附带你的账号 ID 和打码后的邮箱：
  1. 触发了安全规则（被拦下或被婉拒）；
  2. 安全系统临时故障、按降级模式回答；
  3. 你主动点了某条回复的"反馈"。
  审计用于排查问题和调整安全规则，只有我能看到。
- **不要输入敏感信息**：密码、身份证、银行卡、住址等，请不要发给 AI。
- AI 的回复可能出错或编造，不代表站长本人观点。

### 给站长的内部备忘（上线前删掉）

扫描中发现、但不属于对外文字的几件事：

1. **审计表没有保留期限，也没有删除路径**。`nemesis_guard_events` 通过外键 `ON DELETE CASCADE` 跟着用户走，删用户就会删审计；但没有定时清理。建议加一个定期清理（例如 90 天）。
2. **`account` 表存了 OAuth 的 access / refresh / id token**。如果你不需要代表用户调用 Google / Microsoft API，可以考虑不存。
3. **Worker 开了 100% 采样的调用日志**（`wrangler.toml` 的 `observability.logs`），日志里会有 IP 和路径。文字里已经写了，但要知道有这件事。
4. **留言通知用的 webhook 指向你自己的服务**，留言内容会离开 Cloudflare，这一条已写进第 3 节。
5. **联系邮箱不要直接用 `ADMIN_EMAILS` 里的那个**，除非你确定要公开。建议用转发地址或专用邮箱。
